# WeatherAI – AI-Powered Weather Forecasting & Intelligence System

WeatherAI is an AI-powered weather forecasting and intelligence platform that combines machine learning with real-time weather data and historical climate information. The system uses XGBoost models to predict temperature, humidity, and rainfall probability while providing users with understandable weather insights, risk assessment, comfort analysis, travel recommendations, outdoor activity guidance, and climate intelligence.

## Key Technologies

- Python
- XGBoost
- FastAPI
- React
- Vite
- Open-Meteo
- Meteostat
- Machine Learning
- Weather Data Analysis

## Main Features

- Real-time weather information
- ML-based temperature prediction
- ML-based humidity prediction
- Rain probability prediction
- Hourly and daily forecasts
- Weather risk assessment
- Comfort score
- Outdoor activity recommendations
- Travel recommendations
- Historical climate analysis
- Location comparison
- Interactive weather dashboard
- ML model performance visualization
